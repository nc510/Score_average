# 成绩统计分析系统

一个基于 Python Tkinter 开发的 Excel 成绩统计分析系统，支持对"题型分数"工作表进行全面的统计分析。

│  │  文件操作    │  │  统计分析    │  │  关于系统    │     │

## 功能特性

### 1. 文件操作模块
- **打开 Excel 文件**：支持读取 `.xlsx` 和 `.xls` 格式的 Excel 文件
- **保存统计结果**：将统计分析结果导出为 Excel 文件
- **退出系统**：安全退出程序

### 2. 统计分析模块
- **总分统计**：计算各题型的总分
- **平均分计算**：计算各题型的平均分（保留2位小数）
- **最高分/最低分**：找出各题型的最高分和最低分
- **人数统计**：统计参与各题型考试的人数
- **及格率统计**：及格线 60%，计算及格人数和及格率
- **优秀率统计**：优秀线 80%，计算优秀人数和优秀率

### 3. 关于系统模块
- **作者信息**：显示作者姓名、QQ、电话、学校等信息
- **微信二维码**：显示作者微信好友二维码
- **打赏二维码**：显示打赏支持二维码

## 使用说明

### 运行方式

#### 方式一：直接运行 EXE（推荐）
1. 进入 `dist_onedir\成绩统计分析系统\` 目录
2. 双击 `成绩统计分析系统.exe` 启动程序

#### 方式二：使用 Python 运行
```bash
# 激活虚拟环境
cd d:\0_TG\code2026\Score_average\Score_average
.\vv\Scripts\activate

# 运行主程序
python main.py
```

### 操作步骤

1. **打开 Excel 文件**
   - 点击菜单栏「文件」→「打开」
   - 选择包含「题型分数」工作表的 Excel 文件

2. **查看统计结果**
   - 程序自动读取「题型分数」工作表
   - 在主界面的表格中查看各项统计数据

3. **保存统计结果**
   - 点击菜单栏「文件」→「保存统计结果」
   - 选择保存路径和文件名

4. **查看作者信息**
   - 点击菜单栏「关于」→「关于系统」

5. **添加微信好友**
   - 点击菜单栏「关于」→「添加微信好友」

6. **打赏支持**
   - 点击菜单栏「关于」→「打赏支持」
